班级之星 A4 双人打印小工具

面向班级每月评优公示场景的单文件网页工具：浏览器直接打开，A4 横向每页固定展示 2 人，人物绝不跨页，所见即所得。

纯 HTML + 原生 JS 零后端 · 零数据库 localStorage 本地存储 A4 横向打印 每人独立字号

项目背景与痛点

学校班级每月评选班级之星、习惯之星、进步之星，需要打印公示。沿用传统 Word 模板时存在几个反复出现的问题：

  • 每次手动排版，重复调整格式；
  • 多人内容容易跨页、串栏，人物信息被拆分到不同页面；
  • 屏幕预览和实际打印效果不一致，彩色标题容易被打印机转成灰色；
  • 多人录入后分页不可控，排版随时可能崩坏。

目标：做一个本地单 HTML 文件小工具，不用服务器、不用安装软件，浏览器直接打开；A4 横向打印，每页固定 2 位学生，人物不跨页，填写后实时预览。

原始参考模板

参考 Word 文档《初一7班10月班级之星2-模板.docx》，其版式特征如下：

  • A4 横向纸张，一页 2 人，分两栏展示；
  • 顶部标题：班级 + 荣誉称号，黑体红色、黄色描边、居中；
  • 姓名 + 职务同一行，整体右对齐，格式为 姓名（职务、职务）；
  • 照片固定尺寸占位；
  • 简介正文宋体、首行缩进 2 字符，纯黑色文字；
  • Word 原生分栏的缺陷：简介过长会自动串到下一栏，人物信息被拆分跨页。

需求迭代全过程

V1 · 初始需求
基础填写、预览、打印与自动分页
  • A4 纸张，一张打印 2 人；字段含称号、姓名、职务、简介；
  • 表单填写、实时预览、浏览器打印预览与直接打印；
  • 支持多人录入，超过 2 人自动分页；强制单人信息不跨页拆分。
V2 · 版式与排版规则
对齐模板样式，锁定标题与姓名行
  • 标题、姓名职务样式锁定，不参与简介自适应缩放；
  • 只有内容超出卡片才缩小简介字号；放得下就保持原始字号；照片尺寸固定，不压缩；
  • 添加人物时自动填充默认范文模板，直接修改即可；
  • 姓名职务行改为整体右对齐，还原模板布局。
V3 · 字号策略调整
每人独立字号，默认跟随全局基准
  • 删除全局统一缩放逻辑；
  • 全局只保留简介基准字号，仅对新增人物生效；
  • 每位人物可独立设置简介字号，默认跟随全局；单人简介溢出时，仅对该人物向下逐级缩字号，最小 9pt；溢出严重在编辑面板标红警告，提示精简文字，不截断、不跨页。
V4 · UI 布局优化
PC 左右分栏，独立滚动，可拖拽调宽
  • PC 端左侧编辑设置区、右侧 A4 预览区；左右面板独立滚动、互不干扰；支持拖拽调节左侧面板宽度，宽度本地记忆；
  • 移动端自动降级为上下堆叠，小屏适配，标签不折行挤压；
  • 恢复卡片式 UI，分组清晰。
V5 · 文件与图片能力
本地图片上传、历史版本与数据备份
  • 本地选择图片上传，支持照片预览，无需手动粘贴 base64；
  • 本地历史版本：保存多套历史方案、添加备注，支持载入与删除，最多 20 份；
  • JSON 导入导出，用于备份与跨设备迁移；移除废弃的批量粘贴导入功能；
  • 浏览器 localStorage 自动保存当前草稿，刷新不丢失。
V6 · 全局字号与颜色校正
标题 / 姓名字号可配，简介颜色回归黑色
  • 全局标题字号：只改大小，保留红色 + 黄描边、居中、加粗的模板样式；
  • 全局姓名 & 职务字号，保持右对齐，全局统一，不随简介内容自适应；
  • 纠正颜色误判：原 Word 模板简介实测为纯黑单色文字，无渐变；提供黑色、深灰、红色、深蓝、自定义取色。

技术选型

  • 纯前端单 HTML 文件：HTML + CSS + 原生 JavaScript，无框架、无构建；
  • 无后端、无数据库，全部状态在浏览器内维护；
  • 存储：localStorage（当前草稿 + 多份历史版本）；
  • 打印：CSS @page 控制 A4 横向，媒体查询区分屏幕预览与打印样式；
  • 图片：本地选择后在浏览器内压缩为 base64 存储。

踩坑复盘（技术向）

❌ 坑 1：CSS 多栏流式布局，文字会自由流动，人物信息被拆分到两页。 ✅ 解决：放弃流式分栏，改用固定卡片数组分页；每两个人封装成一个 A4 页面容器，强制卡片不可分割。
❌ 坑 2：打印预览和屏幕预览样式不一致，红色标题描边打印变灰。 ✅ 解决：加入 -webkit-print-color-adjust: exact，强制保留打印色彩。
❌ 坑 3：自适应缩放若全局统一进行，会把标题、姓名职务一起缩小，破坏模板样式。 ✅ 解决：元素隔离——仅简介文本做溢出自动缩减，标题、姓名职务、照片尺寸完全锁死。
❌ 坑 4：多人独立字号时，不能改写已有人员；全局基准字号只对新增人员生效。 ✅ 解决：人物对象存储独立字号字段，null 代表跟随全局；修改全局配置不会覆盖已手动设置字号的人。
❌ 坑 5：Word XML 里存在渐变属性，但实际渲染出的 PDF 文字是黑色。 ✅ 解决：不能只看 XML 标签判定样式，必须以实际渲染输出效果为准。
❌ 坑 6：左右分栏时页面整体滚动，编辑区滚动带动预览区滚动，体验割裂。 ✅ 解决：PC 模式两个容器独立滚动；窄屏设备降级为普通文档滚动。

使用小贴士

  • 将工具文件保存为 班级之星打印工具.html，双击用 Edge / Chrome 浏览器打开；
  • 简介建议控制在 380 字以内效果最佳；文字过多时工具会标红提示精简；
  • 打印设置：纸张 A4 横向，关闭“适应边框打印”，缩放保持 100%；
  • 重要资料建议导出 JSON 备份，防止浏览器清理本地存储后丢失数据。
