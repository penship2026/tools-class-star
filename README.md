# 班级之星 A4 打印工具

面向班级每月评优公示场景的**单文件网页工具**：浏览器直接打开即可使用，A4 横向每页固定展示 2 人，人物信息不会跨页拆分，填写内容实时预览、所见即所得。

无需服务器、无需安装、无需构建，纯 HTML + CSS + 原生 JavaScript 实现，数据保存在浏览器本地。

## 功能特性

- **A4 横向双人版式**：一页固定 2 人，超过 2 人自动分页，单个人物卡片强制不可分割
- **还原 Word 模板样式**：标题红色加粗、黄色描边、居中；姓名与职务同一行整体右对齐；简介首行缩进两字符
- **标题自适应**：标题过长时自动逐级降字号（最低 22pt），仍放不下则换行，不再静默截断
- **每人独立简介字号**：默认跟随全局基准字号，内容溢出时仅对该人物的简介逐级缩小（每次 0.5pt，最低 9pt）；标题、姓名职务、照片尺寸锁定
- **长职务不挤掉姓名**：姓名保留最小宽度，职务过长时自己省略，不会出现只剩职务、姓名消失
- **溢出提示**：缩到最小仍放不下时，在编辑面板标红并提示精简文字；该提示与红色虚线**只在屏幕显示，不会打印**
- **本地照片上传**：选择本地图片后在浏览器内压缩为 JPEG（长边最大 1100px，质量 0.85）并以 base64 保存，支持预览与粘贴
- **本地历史版本**：保存多套方案并添加备注，支持载入与删除，最多 20 份；照片按内容去重存储，不会每份快照各存一遍
- **导入安全校验**：导入时校验数据结构、字段类型与图片 data URL，过滤脚本与异常配置；导入前自动把当前内容存为一条历史版本
- **数据文本迁移**：支持「复制数据」把完整 JSON 放进文本框复制，浏览器端用「粘贴导入」恢复，适合从微信搬到电脑；粘贴导入可选覆盖或追加，支持分批次多次导入
- **JSON 导入导出**：用于备份与跨设备迁移，导出文件带 `version` 字段
- **草稿自动保存**：当前数据实时写入 localStorage，刷新不丢失；存储空间不足时会明确提示
- **一键打印 / 导出 PDF**：由 CSS `@page` 控制 A4 横向，强制保留打印色彩；空名单时禁止打印
- **微信环境提示**：在微信内置浏览器中自动显示提示条，点击打印或导出时弹出引导，说明改用外部浏览器
- **PC 左右分栏**：左侧编辑、右侧预览各自独立滚动，左栏宽度可拖拽并本地记忆；窄屏自动降级为上下堆叠，手机端默认收起使用说明

## 快速开始

克隆仓库：

```bash
git clone https://github.com/penship2026/tools-class-star.git
cd tools-class-star
```

也可以只下载 `index.html`。之后用浏览器打开 `index.html`（双击即可），不需要启动任何本地服务。

## 使用说明

1. **全局设置**：填写班级 / 单位、荣誉称号、期次，并设置标题字号、姓名职务字号、简介基准字号和简介字体颜色。全局简介字号只对之后新增的人物生效，不会覆盖已单独调整过的人物。
2. **录入人物**：点击「＋ 添加一人」，填写姓名、职务、简介，可单独设置该人物的简介字号并上传照片。新增人物自带默认范文，直接修改即可。
3. **预览调整**：右侧实时显示 A4 版面，可用「适宽 / 100%」切换预览缩放。
4. **备份迁移**：打开顶部「数据」菜单——用「导出为文件（JSON）」保存备份，换电脑时用「从文件导入（JSON）」恢复；不便传文件时用「复制数据」，在另一台设备用「粘贴导入」恢复（可选择覆盖或追加）。需要保留多套方案时，用「本地历史版本」保存并写清备注。
5. **输出**：点击「打印 / 导出 PDF」。

### 打印设置建议

- 纸张：**A4**；方向：**横向**
- 缩放：**100%（实际大小）**，不要选「适合页面」
- 边距：**无** 或 **最小值**
- 勾选「**背景图形**」可保留照片占位灰底等背景色；标题红字与黄色描边属于文字效果，不受该项影响

在打印对话框中选择「另存为 PDF」即可导出 PDF 文件。页面标题会随班级、称号、期次变化，导出的 PDF 文件名也会带上这些信息。

### 在微信内使用

工具会识别微信内置浏览器（UA 含 `MicroMessenger`）：进入时顶部显示提示条，点击「打印 / 导出 PDF」或「导出数据」会弹出引导，提示点右上角「…」→「在浏览器打开」，或改用电脑 Chrome / Edge。

微信内置浏览器不提供网页打印和文件下载能力，且微信与其他浏览器的本地数据不互通。如需把内容带到电脑：在微信里点「数据」→「复制数据」（或引导弹窗里的「复制数据文本」），再到浏览器里点「数据」→「粘贴导入」恢复，然后打印或导出。

## 数据与隐私

所有数据只保存在当前浏览器的 localStorage 中，不会上传到任何服务器：

| 键名 | 用途 |
| --- | --- |
| `class_star_tool_v1` | 当前草稿 |
| `class_star_history_v1` | 本地历史版本（最多 20 条） |
| `class_star_photos_v1` | 历史版本照片池（按内容去重） |
| `class_star_layout_v1` | 左侧编辑栏宽度 |
| `class_star_guide_v1` | 使用说明展开状态 |

清理浏览器数据、更换浏览器或使用无痕模式都会导致数据丢失，重要内容请及时「导出数据」备份。「数据」菜单里的「清空全部」会同时清除当前内容、全局设置与本地历史版本。

> 导出的 JSON 包含真实姓名、简介和照片，**不要提交到公开仓库或随意外发**。

## 技术说明

- 纯前端单 HTML 文件，无框架、无构建、无第三方依赖
- 分页不使用 CSS 多栏流式布局，而是固定卡片数组：每 2 人封装进一个 A4 页面容器，配合 `break-inside: avoid` / `break-after: page`，从根上避免 Word 多栏排版常见的跨页串栏
- 打印样式由 `@page { size: A4 landscape; margin: 0 }` 与 `-webkit-print-color-adjust: exact` 控制；溢出提示、红色虚线、空状态页在 `@media print` 中隐藏
- 图片经 `<canvas>` 压缩为 JPEG 后以 data URL 存入 localStorage；渲染时通过属性赋值与 HTML 转义双重防护，导入时再做白名单校验（仅允许 jpeg / png / webp 的 base64 data URL）
- 字号自适应只作用于简介文本：按基准字号生成 0.5pt 递减的档位（最低 9pt），逐档试探直到内容放得下
- 历史版本中的照片以 `@ref:` 引用保存在独立照片池，同一张照片多份快照只存一份，避免 localStorage 配额被快速耗尽
- 复制数据优先使用 Clipboard API，失败时回退到 `execCommand("copy")`；弹窗内保留只读文本框，必要时可长按全选手动复制

修改方式：直接编辑 `index.html` 里的 `<style>` / `<script>`，刷新浏览器即可看到效果，无需编译或打包。

## 浏览器兼容

建议使用 Chrome / Edge（Chromium 内核）打开并打印，版面与色彩还原最可控。使用 Safari 或 Firefox 时，请在打印预览中确认纸张方向、缩放比例与「背景图形」选项是否生效。微信内置浏览器只建议用于填写和预览，打印与导出请改用系统浏览器。
