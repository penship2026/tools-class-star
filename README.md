# 班级之星 A4 打印工具

面向班级每月评优公示场景的**单文件网页工具**：浏览器直接打开即可使用，A4 横向每页固定展示 2 人，人物信息不会跨页拆分，填写内容实时预览、所见即所得。

无需服务器、无需安装、无需构建，纯 HTML + CSS + 原生 JavaScript 实现，数据保存在浏览器本地。

## 功能特性

- **A4 横向双人版式**：一页固定 2 人，超过 2 人自动分页，单个人物卡片强制不可分割
- **还原 Word 模板样式**：标题红色加粗、黄色描边、居中；姓名与职务同一行整体右对齐；简介首行缩进两字符
- **每人独立简介字号**：默认跟随全局基准字号，内容溢出时仅对该人物的简介逐级缩小（每次 0.5pt，最低 9pt）；标题、姓名职务、照片尺寸完全锁定，不参与缩放
- **溢出提示**：缩到最小仍放不下时，在编辑面板标红并提示精简文字，不截断、不跨页
- **本地照片上传**：选择本地图片后在浏览器内压缩为 JPEG（质量 0.85）并以 base64 保存，支持预览
- **本地历史版本**：保存多套方案并添加备注，支持载入与删除，最多 20 份，超出自动淘汰旧记录
- **JSON 导入导出**：用于备份与跨设备迁移
- **草稿自动保存**：当前数据实时写入 localStorage，刷新不丢失
- **一键打印 / 导出 PDF**：由 CSS `@page` 控制 A4 横向，强制保留打印色彩
- **PC 左右分栏**：左侧编辑、右侧预览各自独立滚动，左栏宽度可拖拽并本地记忆；窄屏自动降级为上下堆叠

## 快速开始

克隆仓库：

```bash
git clone https://github.com/penship2026/tools-class-star.git
cd tools-class-star
```

也可以只下载 `index.html`。之后用浏览器打开 `index.html`（双击即可），不需要启动任何本地服务。

## 使用说明

1. **全局设置**：填写班级 / 单位、荣誉称号、期次，并设置标题字号、姓名职务字号、简介基准字号和简介字体颜色。全局简介字号只对之后新增的人物生效，不会覆盖已单独调整过的人物。
2. **录入人物**：点击「＋ 添加一人」，填写姓名、职务、简介，可单独设置该人物的简介字号并上传照片。新增人物自带默认范文，直接修改即可。
3. **预览调整**：右侧实时显示 A4 版面，可用「适宽 / 100%」切换预览缩放。
4. **备份迁移**：用「导出数据」保存 JSON；换电脑时用「导入数据」恢复。需要保留多套方案时，用「本地历史版本」保存并写清备注。
5. **输出**：点击「打印 / 导出 PDF」。

### 打印设置建议

- 纸张：**A4**；方向：**横向**
- 缩放：**100%（实际大小）**，不要选「适合页面」
- 边距：**无** 或 **最小值**
- 勾选「**背景图形**」（Chrome / Edge 打印对话框的「更多设置」中），否则标题描边等彩色效果可能丢失

在打印对话框中选择「另存为 PDF」即可导出 PDF 文件。

## 数据与隐私

所有数据只保存在当前浏览器的 localStorage 中，不会上传到任何服务器：

| 键名 | 用途 |
| --- | --- |
| `class_star_tool_v1` | 当前草稿 |
| `class_star_history_v1` | 本地历史版本（最多 20 条） |
| `class_star_layout_v1` | 左侧编辑栏宽度 |

清理浏览器数据、更换浏览器或使用无痕模式都会导致数据丢失，重要内容请及时「导出数据」备份。

## 技术说明

- 纯前端单 HTML 文件，无框架、无构建、无第三方依赖
- 分页不使用 CSS 多栏流式布局，而是固定卡片数组：每 2 人封装进一个 A4 页面容器，配合 `break-inside: avoid` / `break-after: page`，从根上避免 Word 多栏排版常见的跨页串栏
- 打印样式由 `@page { size: A4 landscape; margin: 0 }` 与 `-webkit-print-color-adjust: exact` 控制
- 图片经 `<canvas>` 压缩为 JPEG 后以 data URL 存入 localStorage
- 字号自适应只作用于简介文本：按基准字号生成 0.5pt 递减的档位（最低 9pt），逐档试探直到内容放得下

修改方式：直接编辑 `index.html` 里的 `<style>` / `<script>`，刷新浏览器即可看到效果，无需编译或打包。

## 浏览器兼容

建议使用 Chrome / Edge（Chromium 内核）打开并打印，版面与色彩还原最可控。使用 Safari 或 Firefox 时，请在打印预览中确认纸张方向、缩放比例与「背景图形」选项是否生效。
